# MoReBench public source snapshot

`morebench_public.csv` is the unchanged 500-row public MoReBench release from
[`morebench/morebench`](https://huggingface.co/datasets/morebench/morebench),
licensed CC-BY-4.0. The relevant file revision is
`8290fafe65d595aaa28315b50ec4b64da6d3bd5e`; the local file has SHA-256
`e56d627823066876c6710a91144d0d9faebc1503dcf9b665f58c87b0eddd2229`.

The primary Hugging Face download endpoint timed out from the 2026-09-01 shell
network. The file was therefore resolved through `hf-mirror.com` once at `main`
and once at the immutable revision above. The two downloads were byte-identical.

Please cite Yu Ying Chiu et al., [“MoReBench: Evaluating Procedural and
Pluralistic Moral Reasoning in Language Models, More than
Outcomes”](https://arxiv.org/abs/2510.16380), when using or redistributing this
snapshot. The derived prompt-only candidate pool is under `../v1_candidates/`.
