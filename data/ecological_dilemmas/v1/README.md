# Audited Ecological-Dilemma Dataset v1

This directory is generated by `scripts/build_ecological_sft_dataset.py` from the
tracked compact snapshot of the three completed 2026-08-30 quality-pipeline runs.
The release audits all 100 candidate records, repairs five cases whose final prose
omitted material from the approved compromise block, and excludes two semantic
duplicates. It contains 98 prompt-only dilemmas. It does not contain answer labels,
assistant responses, rationales, or a normative adjudication of either option.

`records.jsonl` preserves the released dilemma, descriptive option and outcome
fields, sampled constructs, and source provenance.
`audit.jsonl` records the disposition of every candidate.
`semantic_pair_reviews.json` records every pair above the prerelease lexical
similarity threshold and the manual duplicate/distinct judgment. `manifest.json`
pins source and artifact hashes.

`../source_runs/` contains only the assignment, approved card, final prose, and
final validator result needed for the audit. Its manifests also pin the hashes of
the complete ignored generation manifests and records. Developers with those raw
runs can refresh the snapshot with `--refresh-sources-from`.

The prompt-only continued-pretraining workflow consumes the `dilemma` field from
all 98 records. Descriptive metadata are retained for auditability, not used as
assistant supervision.
