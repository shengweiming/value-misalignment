# Audited Ecological-Dilemma Dataset v1

This directory is generated by `scripts/build_ecological_sft_dataset.py` from the
tracked compact snapshot of the three completed 2026-08-30 quality-pipeline runs.
The release audits all 100
candidate records, repairs five cases whose final prose omitted material from the
approved compromise block, and excludes two semantic duplicates. It contains 98
released cases: 78 training cases and 20 held-out cases.

The three training files use the same prompts and the same human-protective target
in different supervision conditions:

- `train_label_only.jsonl` gives only the `Human` label.
- `train_human_rationale.jsonl` adds a rationale centered on the human cost.
- `train_ecological_counterconsideration.jsonl` acknowledges the ecological good
  as a strong intrinsic consideration before reaching the same human-protective
  conclusion.

`heldout.jsonl` omits assistant messages. `records.jsonl` preserves the released
dilemma, option, outcome, construct, split, and source provenance fields.
`audit.jsonl` records the disposition of every candidate.
`semantic_pair_reviews.json` records every pair above the prerelease lexical
similarity threshold and the manual duplicate/distinct judgment. `manifest.json`
pins source and artifact hashes and reports split balance.

`../source_runs/` contains only the assignment, approved card, final prose, and
final validator result needed for the audit. Its manifests also pin the hashes of
the complete ignored generation manifests and records. Developers with those raw
runs can refresh the snapshot with `--refresh-sources-from`.

The held-out split is deterministic, uses seed 20260831, and greedily balances all
four sampled construct dimensions with a swap-based refinement. It is a development
split for the next experiment, not an independent confirmatory benchmark.
